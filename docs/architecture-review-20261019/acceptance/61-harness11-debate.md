## 二、辩论焦点二：经验感知提议器的动作空间（自由生成 vs 紧致离散变异算子池）

### 2.1 各方论点陈述
- **智能体 A（理论审计员）**：
  提出**有限 VC 维定理（定理 1）**与**泛化误差界定理（定理 2）**：若允许 LLM 基于历史经验自由生成自然语言 Prompt，假说空间 VC 维为无穷大，模型容易陷入“测试用例实体记忆与查表过拟合”；只有将动作空间严格约束在有限离散代数变异算子池 $\mathcal{M}$（$|\mathcal{M}|=4$）上，变异假说空间大小 $|\mathcal{H}_{\text{mut}}| \le 20$，VC 维严格受限于 $\le 4.32$，跨任务泛化误差界分子精确受控于 $\ln |\mathcal{H}_{\text{mut}}|$，能以 $\mathcal{O}(N^{-1/2})$ 快速收敛。
- **智能体 B（工程审计员）**：
  工程落地中，以既有的 `AlgebraicHarnessMutator` 的 4 大算子（`CONCISE_SYSTEM_PROMPT`, `GUARDRAIL_TIGHTENING`, `ADAPTIVE_MEMORY_WINDOW`, `TOOL_GUIDANCE_SYNTHESIS`）为基底，通过 `ExperienceRecallGateway` 将经验库转化为算子权重的 Softmax 分布，选择 Top-2 正交算子生成候选凭单。
- **智能体 C（合规监察员）**：
  从防注入与运行时纯洁性角度指出，离散算子模式确保了生成的凭单依然是静态、不可变的结构化参数，**经验绝不直接进入运行期 SystemPrompt**，彻底保护了 DeepSeek 的静态前缀缓存（KV Cache），并杜绝提示词注入攻击。

### 2.2 主裁决裁定
**【统一裁决】**：**坚决否决由 LLM 自由生成 Prompt 的无界模式，全票采纳智能体 A 的离散变异算子池设计**！
- 经验库在提议阶段的作用被严格定义为“变异算子选择的后验概率调制器”；
- 生产在线执行端继续消费带有 SHA-256 签名的静态不可变凭单，经验库对运行时保持绝对透明与零动态拼接。

## 三、辩论焦点三：递归 PPC 轮次状态机与终态停止条件

### 3.1 各方论点陈述
- **智能体 B（工程审计员）**：
  设计了两轮递归状态机 `PpcRecursiveLoop` 与硬性停止器 `PpcStopPolicy`：
  - Round 1：以 baseline 为基础，提议 2 个经验候选并执行评测；
  - Round 2：仅当 Round 1 产生了超越 baseline 的胜出候选 $C^*$ 时方可触发，以 $C^*$ 为新基准微调生成二阶候选；
  - 硬性停止：最多 2 轮（$R \le 2$），一旦某一轮未击败轮次基准，立即无条件终止并保留前置基准。
- **智能体 A（理论审计员）**：
  提出**离线评测探针集经验风险有界截断定理（定理 3）**：在离线评测探针集上，递归优化最差情况下的经验风险由基线完全截断（$\hat{R}_N(V^*) \le \hat{R}_N(V_0)$）；开放域期望风险受控于泛化上界。同时引入边际收益递减判据 $|\Delta u_t - \Delta u_{t-1}| \le \epsilon$，当第二轮提升幅度微弱时提前终止。
- **智能体 C（合规监察员）**：
  要求多轮证据链传递（`PpcRoundEvidence`）必须完整记录每一轮的候选凭单指纹、各探针指标与判决理由，禁止在多轮递归中丢失任何一轮的审计快照。

### 3.2 主裁决裁定
**【统一裁决】**：全票采纳两轮状态机设计，锁定硬性最大轮次 $R \le 2$：
- 严格执行四大停止条件：达到 2 轮上限、轮次无改善、边际增益收敛（$\le 0.001$）或资源预算耗尽；
- 杜绝一切无界递归探索，保障纯机制执行的确定性收敛。

## 四、辩论焦点四：经验准入过滤、负经验分层与 100% 跨域互斥率

### 4.1 各方论点陈述
- **智能体 C（合规监察员）**：
  强调四道防线与负经验分层机制：
  1. `UNSCOPED_REPLAY` 实行“门面短路 + 条目实体不变量”双重一票否决，对任何业务域 100% 隔离阻断；
  2. 彻底厘清负经验机制：Stage 9 得出的全局教训（如提示词不可过度精简）属于**系统级全局架构不变式**，直接硬编码在算子池元数据中；而运行期的 `negativeExclusionMasks` 仅承载**本业务域内部**探索失败的局部条目，绝不跨域读取 `UNSCOPED_REPLAY`；
  3. `ExperienceLeakageGuard` 必须升级为“动静双层网关”，防止新的评测实体泄漏；
  4. 跨 Domain 隔离必须在单测中以合成多业务域（金融、电信、医疗）断言互斥率严格达到 100%。
- **智能体 A（理论审计员）**：
  从超球面高维测度集中（Concentration of Measure）证明了准则 3（余弦相似度下限 $\cos\theta \ge 0.65$）的必要性，防止因语义距离过远导致假因果注入。
- **智能体 B（工程审计员）**：
  在 `ExperienceRecallGateway` 中落地了正负经验分离（`positiveLessons` vs `negativeExclusionMasks`）的强类型 Record 接口。

### 4.2 主裁决裁定
**【统一裁决】**：全票采纳智能体 C 的分层隔离防线与智能体 A 的四大忽略准则：
- 任何处于 `UNSCOPED_REPLAY`、`retired == true`、`confidence < 0.20` 或 `failureObserved == true` 的条目，绝对禁止进入正向提议集合；
- `UNSCOPED_REPLAY` 对业务域保持 100% 互斥与零召回，禁止将 Stage 9 回放条目作为动态掩码跨域注入业务域；
- 在自动化测试中必须包含合成多业务域 100% 互斥率断言。
