# Phase 42: 具身智能体空间环境感知、数字孪生交互与具身控制回路 实施方案

## 一、方案背景与目标

前 41 个 Phase 的建设使全系统在文本、向量、图谱、网关、多智能体与分布式高可用上具备了强大能力。进入 **Phase 42**，系统正式拓展至**具身智能体物理空间感知、数字孪生仿真推演与闭环安全控制**领域。

本阶段的核心目标在于：
1. **建立李群 $\text{SE}(3)$ 空间几何度量与语义拓扑图**：实现精确的三维空间位姿表示与定向包围盒（OBB）距离测算，空间定位误差限制在 $\le 5\text{cm}$，消除空间几何幻觉（定理 1.1）；
2. **构建数字孪生仿真沙盒与前向反事实推演**：在真实动作下发前，在纯内存数字孪生环境完成 $H$ 步前向虚拟步进（Rollout），碰撞检出率 $\ge 99\%$；
3. **物理不可逆操作绝对安全硬门禁**：对物理不可逆（`IRREVERSIBLE`）或高风险动作实施严格安全凭证与数字孪生推演双重校验，未经仿真验证通过的不可逆动作误执行率严格为 0（定理 3.1）；
4. **闭环轨迹控制与态势对账**：实现闭环步进控制回路，动作执行后即时进行几何态势对账，避免开环盲操作，收敛时间 $\le 1000\text{ms}$（定理 2.1）；
5. **10 项严苛契约测试 100% 绿灯**，后端全量防退化回归测试保持 100% 通过（0 失败 0 错误），前端生产打包 0 错误。

## 二、唯一待验证假设与契约测试

**唯一待验证假设 (H-PHASE42-001)**：
> 在三维空间交互场景下，通过构建基于李群 $\text{SE}(3)$ 刚体变换的度量语义拓扑图与数字孪生前向推演沙盒，结合控制屏障函数对不可逆操作实施硬件级门禁拦截，空间定位误差限制在 $\le 5\text{cm}$，无碰撞闭环控制收敛率 $\ge 98\%$，且未经验证的物理不可逆操作穿透执行率严格为 0。

**10 项严苛契约测试设计 (`Phase42EmbodiedSpatialControlContractTest.java`)**：
1. **$\text{SE}(3)$ 空间位姿齐次变换与距离不变性契约**（定理 1.1，任意平移旋转下两物体间相对欧式距离保持不变）；
2. **三维定向包围盒（OBB）相交与高精度碰撞干涉检测契约**（定理 1.1，重叠包围盒检出率 100%，无交集包围盒距离严格准确）；
3. **空间相对方位语义解析契约**（左/右/前/后/上/下基于观察者坐标系精准映射，消除空间方向幻觉）；
4. **数字孪生环境虚拟快照克隆与轻量隔离契约**（孪生沙盒与真实物理状态完全解耦，虚拟推演零物理副作用）；
5. **数字孪生多步前向推演（Counterfactual Rollout）干涉检出契约**（预测轨迹与障碍物相交动作被 100% 预警）；
6. **物理不可逆操作（IRREVERSIBLE）门禁绝对阻断契约**（定理 3.1，缺乏安全凭证或仿真失败时 100% 物理拦截）；
7. **合规安全凭证（Safety Ticket）授权放行契约**（仿真通过且附带有效凭证的不可逆动作正常执行）；
8. **可逆动作（REVERSIBLE）快速通道放行契约**（安全低风险动作免重型审批极速通行）；
9. **闭环控制执行后态势确认（Post-check）与滑脱故障检出契约**（抓取后物体空间位置未跟随判定为动作失败）；
10. **端到端具身任务规划、孪生推演与闭环执行全链路闭环契约**（定理 2.1，任务从空间解析->仿真校验->闭环执行->状态对账顺利完成，收敛时间 $\le 1000\text{ms}$）。

## 三、代码组件落地清单

代码落盘路径：`backend/qknow-framework/qknow-ai/src/main/java/tech/qiantong/qknow/ai/embodied`

### 1. 数据传输与状态对象 (DTO/VO)
- `dto/SpatialPose3D.java`: 三维位姿实体（坐标 $x, y, z$ 与欧拉角 roll, pitch, yaw，欧氏距离计算）；
- `dto/BoundingBox3D.java`: 三维定向包围盒（中心坐标、长宽高尺寸、OBB 空间包含与碰撞相交检测）；
- `dto/SpatialEntityDO.java`: 空间实体对象（ID、语义标签、1536维千问向量、当前位姿、包围盒、是否可移动）；
- `dto/ActionPrimitiveDTO.java`: 动作控制原语（原语类型、目标实体 ID、目标位姿、可逆性等级、力矩限制、安全凭证）；

### 2. 核心业务引擎组件
- `engine/SpatialGridGraph.java`: 3D 度量语义拓扑栅格图（管理多实体空间分布、空间距离与相对方位角计算、碰撞干涉检视）；
- `engine/DigitalTwinSimulator.java`: 数字孪生仿真沙盒（环境快照克隆、多步前向虚拟步进推演、轨迹碰撞与力矩边界预警）；
- `engine/ActuationSafetyGate.java`: 物理执行安全门禁（不可逆操作拦截、控制屏障函数校验、安全凭证核销）；
- `engine/ClosedLoopController.java`: 具身控制回路协调器（端到端任务规划、孪生预推演、门禁拦截与执行后态势对账）。
