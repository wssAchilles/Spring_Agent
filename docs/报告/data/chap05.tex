\chapter{总结与展望}

\section{工作总结}

本文设计并实现了一个基于 RAG 与多智能体协作的知识服务平台，围绕"检索—推理—编排—评估"四个核心环节，在架构设计、算法实现和工程落地方面取得了以下主要成果：

（1）设计了"控制面＋认知面"双核架构，通过 gRPC 实现业务逻辑与 AI 推理的完全解耦。控制面承担鉴权、数据库 I/O、会话管理等有状态职责，认知面保持绝对无状态化，仅负责 LLM 推理与工具调度。该架构使得两个平面可独立扩缩容，认知面可按需水平扩展以应对高并发推理请求，而控制面则专注于数据一致性保障。

（2）实现了四路并行召回＋RRF 融合的 RAG 检索引擎，引入 CRAG 机制进行检索质量评估与条件二次检索。向量检索、关键词检索、元数据检索和知识图谱检索四条路径通过线程池并行执行，RRF 融合算法对多路结果进行归一化排序，弱路径淘汰策略自动过滤低置信度召回源，有效提升了检索的鲁棒性和准确率。

（3）提出了带自洽性检测的反思循环推理机制，通过 Jaccard 相似度识别幻觉回答，双重门限确保回答质量。AI Judge 对生成结果从事实性、相关性和指令遵循度三个维度进行量化评分，评分反馈注入后续轮次的提示词形成闭环优化，使模型能够在多轮迭代中逐步修正错误回答。

（4）实现了基于 DAG 拓扑排序的工作流并行执行引擎，支持 8 种节点类型和双层持久化检查点。BFS 分层算法将 DAG 划分为多个可并行执行的节点组，结合 CompletableFuture 异步调度实现了任务级并行。Human-in-the-loop 审批节点采用异步挂起/唤醒机制，支持超时降级和人工回调。

（5）构建了集成 AI Judge、RAGAS、RAGChecker 和 LangFuse 的完整质量评估与可观测性体系。RAGAS 从七个维度量化 RAG 生成质量，RAGChecker 在声明级粒度判断蕴含关系，LangFuse 提供端到端的 Trace 追踪和延迟分析，三者形成了从宏观到微观的立体化评估能力。

（6）实现了三层记忆体系和 MCP 协议适配，支持跨会话知识持久化和外部工具动态注册。短期记忆支持内存和 Redis 双模式，长期记忆基于向量存储实现语义检索，情景记忆通过 Session 持久化保留完整对话轨迹。MCP 协议适配层使系统能够动态接入外部工具，扩展了智能体的能力边界。

\section{不足与展望}

\subsection{当前不足}

尽管系统在功能和性能方面达到了预期目标，但仍存在以下不足之处：

（1）自洽性检测使用词级 Jaccard 相似度，仅能捕捉词汇层面的重叠，无法识别语义等价但表述不同的回答，可能导致误判。例如，"使用 PostgreSQL 数据库"和"采用 Postgres 作为持久层"在语义上等价，但词级相似度较低。

（2）记忆系统默认使用内存存储，服务重启后短期记忆丢失，无法满足生产环境的持久化需求。长期记忆虽基于向量存储，但缺乏自动化的记忆衰减和整合机制，可能导致过时信息持续影响检索结果。

（3）评估模型与生成模型相同（均为 DeepSeek deepseek-chat），存在自我评价偏差的风险。模型可能倾向于给与自身生成风格相似的回答更高的评分，影响评估结果的客观性。

（4）测试覆盖率约 5\%，缺少 CI/CD 流水线。当前测试主要集中在核心算法逻辑，控制器层和数据访问层的测试覆盖不足，且未配置自动化构建和部署流程。

\subsection{未来展望}

针对上述不足，未来工作将围绕以下方向展开：

（1）\textbf{升级 Spring AI 2.0}，解决当前版本的兼容性问题并使用新的流式 API 和工具调用规范，简化框架层代码。

（2）\textbf{引入语义自洽性检测}，用嵌入余弦相似度或 NLI 模型替代词级 Jaccard，提升对语义等价表述的识别能力，降低误判率。

（3）\textbf{实现 Contextual Retrieval}\cite{Anthropic2024ContextualRetrieval}，为每个文档块添加上下文前缀信息，预期可降低检索失败率 67\%，显著提升跨文档段落的检索准确率。

（4）\textbf{完善测试与 CI/CD}，补充控制器层和数据层的单元测试与集成测试，配置 JaCoCo 覆盖率报告和 GitHub Actions 自动化流水线，实现代码提交后的自动构建、测试和部署。

（5）\textbf{引入时序知识图谱和 HyPE 索引优化}，为知识图谱中的实体和关系添加时间戳维度，支持时序感知的推理和检索；HyPE 索引通过层次化向量编码提升大规模知识库的检索效率。

（6）\textbf{实现分布式部署}，通过 Kubernetes 编排实现控制面和认知面的独立扩缩容，结合服务网格（Service Mesh）实现细粒度的流量控制和故障隔离，提升系统在生产环境下的可用性和弹性。
