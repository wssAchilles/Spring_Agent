# ASOC 论文与实验局部工作规则

本文件只约束 `/Users/achilles/Documents/许子祺/Agent/ASOC/` 内的论文、数据处理、实验和研究产物。它是 ASOC 项目提示与实验技能的执行索引，不替代或削弱上级 `/Users/achilles/Documents/许子祺/Agent/AGENTS.md`；发生冲突时遵守更高优先级要求。每次实质工作前重新读取与该阶段相关的本地 `skills/*/SKILL.md`。

## 1. 仓库与数据边界

- 论文相关工作仅在专用分支 `codex/paper` 进行；不得切换到或修改 `main`。
- 实验脚本、配置、日志、结果、图表、证据清单和稿件均保存在本目录内。
- `data/` 中已下载的数据是输入资产。除非用户明确要求，不覆盖、移动、清理、重命名或提交原始数据；外部数据的许可状态须分别核实，代码仓库许可证不自动覆盖数据。
- 算法实验不得顺手修改 Agent 主仓库的生产代码、配置、fixture、qrel 或通过阈值。生产实现、参数调整、A/B、promotion 与线上启用均须单独授权。
- 任何 API、数据库、网络或计费资源调用，须先确认调用路径、凭据来源和预算；未冻结预算时优先使用可复现的离线实验。

## 2. 科研准入与假设

- 算法研究先读取当前分支的真实执行路径、输入输出、持久化、配置、异常/fallback、测试和已有实验；索引结果必须以当前源文件复核。
- 每阶段只保留一条明确、可证伪的主假设，并把其他机制拆成独立消融或后续阶段。若不能区分因素，输出 `RESEARCH_GATE_BLOCKED`。
- 新算法候选使用 3–6 个直接相关的一手来源；对全文或固定版本实际读取后，按项目规定记录完整 14 字段 Research Ledger。摘要或搜索摘要不得标为 `VERIFIED`。
- 报告按 A–G 顺序完成：代码与失败机制、Research Ledger、迁移性、候选比较、最小推荐、冻结实验/实现计划、风险与授权边界。
- 实施前冻结输入、候选定义、baseline、qrel、划分、统计单位、指标、停止条件、资源预算、文件范围和复现命令。首次结果出来后，不得改 qrel、数据分布、阈值或判定标准以追求改善。

## 3. 数据与因果解释

- `LongMemEval S` 的 `answer_session_ids` 是 session-level 检索证据标签；它们不是生成答案的完整 gold，也不自动等价于生产压缩摘要的标签。必须明确并验证候选记忆到源 session 的映射。
- 对 LongMemEval 的跨题共享 session 结构，不得随机切题并声称独立 holdout。若不能建立互不泄漏且独立的 selection/holdout 单元，只报告探索性描述统计，不声称泛化或统计显著性。
- MSC 的 train/validation/test 划分不等同于检索 qrel；MemoryBank-SiliconFriend 的探针问题在缺少 gold answer/证据 ID 时不得用于监督或计算检索准确率。
- 时间戳只能提供记忆年龄，不能定义一条记忆“应保留”或“应遗忘”。遗忘主张需要预先标注的时间序列、保留/遗忘目标及反事实。
- `Friedman`、`Wilcoxon`、`Nemenyi` 等检验仅在统计单位、独立性、配对关系和多重比较方案预先成立时使用；不得为满足期刊格式而滥用检验。

- 重新审计 `LongTermMemory` 与 `ReflectiveMemoryCoordinator` 两条路径，不得把它们描述为同一排序器或同一记忆状态。
- 对已核验的 `LongTermMemory` 路径，源码实际采用相似度、留存、重要度和图激活的固定权重标量排序；注释中的 “Pareto” 不构成非支配排序实现证据。
- 长期记忆强化状态、查询分数语义、用户隔离、scope、检索候选集与摘要持久化均须以当前代码和运行验证为准。理论公式、测试名称和注释不得替代执行证据。
- 任何 benchmark proxy（如词项检索替代 Qwen 向量检索）必须在实验名称、报告和论文中明示，不得称为生产路径或真实模型结果。
